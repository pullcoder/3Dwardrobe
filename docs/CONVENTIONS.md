# 코딩 규칙

- 문서·주석은 한국어, 식별자는 영어. UTF-8/LF, Python 4칸, TS/CSS 2칸.
- React 함수형 컴포넌트·훅, TypeScript strict, `any` 금지. 서버 호출은 `src/api/`만 사용.
- API snake_case를 TS 응답 타입에서도 그대로 유지한다.
- 이미지는 정해진 컴포넌트에서 객체 URL을 만들고 해제한다. 사진·평문 치수 localStorage/로그 금지. 체형의 명시적 기기 저장은 BodyVault의 허용 필드·AES-GCM 암호화 경로만 사용한다.
- 입력 데이터에 개인정보를 넣은 오류 메시지·telemetry를 만들지 않는다.
- FastAPI 라우터는 요청 경계, 실제 검증은 services, 응답은 Pydantic으로 분리한다.
- 개발 환경에서만 허용되는 제약과 실제 동작을 문서화한다. AI/생성/영구 저장을 모사하지 않는다.
- 치수에는 단위와 의미·출처를 포함한다. 신체 둘레와 의류 단면 너비를 같은 필드로 쓰지 않는다.
- 모델 후보를 승인된 모델처럼 취급하지 않는다. 모델 도입 때 감사 문서를 갱신한다.
- 배포·DB 단계에서 마이그레이션과 소유권 검사를 추가한다.
- 5단계 최소 체형 수치의 서버 저장은 별도 동의와 저장 동작이 필요하다. 원본 사진/관절/얼굴을 피팅 API에 넣지 않는다. 서버 저장과 기존 BodyVault 기기 암호화 저장을 혼동하지 않는다.
- ESLint/React Hooks/접근성 린트, Prettier, ruff, pytest, Playwright를 사용한다.
- 라이브러리 버전은 npm lock·Python lock으로 재현한다. 테스트는 동작 경계·사용자 흐름 위주로 둔다.
