## D-010. 3D 인체 메시: SMPL 직접 사용 금지, 교체 가능한 구조
- 날짜: 2026-11-02 / 결정자: 사업계획서 최종 / 상태: 확정
- 배경: SMPL/SMPL-X는 MPI 비상업용 라이선스라 상용 서비스에 그대로 쓸 수 없다.
- 결정: M+6 3D 아바타는 상업 이용이 허용된 오픈소스 메시(MakeHuman 기반 인체 메시 등)를 기본으로 하고, 필요하면 SMPL 정식 유료 라이선스를 계약한다. 코드에서는 `BodyMeshModel` 인터페이스 뒤에 두어 교체 가능하게 만든다.
- 대안: SMPL 그대로 사용(법적 위험).
- 영향: SMPL 가중치·코드는 라이선스 계약 전까지 저장소에 넣지 않는다. 사용하는 메시의 라이선스를 이 문서에 기록한다.

## D-011. 비동기 추론: MVP부터 Celery + Redis
- 날짜: 2026-11-02 / 결정자: 사업계획서 최종 / 상태: 확정
- 배경: GPU 서버 비용과 처리 속도. 사진 처리 요청이 몰리면 API 서버가 막힌다.
- 결정: FastAPI는 작업을 큐에 넣고 바로 응답, AI 추론은 Celery 워커가 처리. Redis를 브로커·결과 저장소로 사용.
- 대안: FastAPI `BackgroundTasks`(서버와 같은 프로세스라 분산 불가) — 처음 초안에서 대체.
- 영향: 로컬 개발에 Redis 필요(docker compose), 워커 실행 명령 추가(`SETUP.md`).

## D-012. 매칭 점수: 컬러 하모니 + 스타일 가중치 + 코사인 유사도, 0~100점, 임계값 70
- 날짜: 2026-11-02 / 결정자: 사업계획서 최종 / 상태: 확정 (가중치는 조정 대상)
- 배경: 단순 코사인 유사도만으로는 "어울림"을 설명하기 어렵다.
- 결정: VLM이 뽑은 색상 팔레트·소재·패턴·스타일 태그로 ① 컬러 하모니 룰 점수 ② 스타일 매칭 가중치 ③ 태그 임베딩 코사인 유사도를 합산해 0~100점. **70점 이상 = 어울리는 코디**. UI는 "옷장 속 N벌과 70점 이상으로 어울립니다".
- 영향: 가중치·임계값은 `.env`(`MATCH_SCORE_THRESHOLD`)와 설정 코드로 관리, 사용성 테스트로 조정. 점수 구성(`breakdown`)을 API로 내려 추천 이유를 보여준다.

## D-014. 의류 누끼: K-Fashion으로 학습한 부위 세그멘테이션 + 부풀린 3D 메시
- 날짜: 2026-11-06 / 결정자: (팀 확인 필요) / 상태: 제안
- 배경: 옷장 등록은 한 사진에서 상의·하의·아우터를 따로 떼어야 한다. RMBG/SAM은 '전경 전체'만 떼어 부위를 나누지 못한다.
- 결정:
  - 모델: torchvision DeepLabV3-MobileNetV3-Large(코드 BSD-3)를 AI Hub 'K-Fashion 이미지'(dataSetSn=51) 폴리곤으로 미세조정(옷만 찍은 사진이 많은 '의류 가상착용 3D 이미지 업사이클링'(dataSetSn=71940)도 LabelMe 형식으로 함께 학습 가능), 5클래스(배경/상의/하의/아우터/원피스). CPU 워커에서도 돌아가는 크기.
  - 3D: 누끼 마스크를 거리변환으로 부풀린 닫힌 메시 + 누끼 텍스처, `.glb`로 저장. MVP 데모용 입체 카드 수준이며 실제 옷 형태 복원·드레이핑은 T2-4에서 다시 정한다.
  - 가중치 경로는 `AI_WEIGHTS_DIR` 한 곳에서 읽는다 (폴더 이름 미결정 대응).
- 라이선스 확인 필요:
  - K-Fashion: AI Hub 이용약관상 데이터 재배포 금지. 저장소에 데이터·샘플을 넣지 않는다. 학습 결과 모델의 상업 이용 조건은 AI Hub 약관 확인 후 기록.
  - ImageNet 사전학습 백본 가중치(torchvision 제공): ImageNet 이용 조건 확인 필요. 문제가 되면 `--no-pretrained`로 처음부터 학습.
  - RMBG-1.4(BRIA)는 비상업 라이선스(상업 이용은 별도 계약)라 기본 파이프라인에 넣지 않았다. SAM(Apache-2.0)은 경계 보정용으로 추가 가능.
- 대안: SAM에 박스 프롬프트(검출 모델 필요), 상용 배경 제거 API.
