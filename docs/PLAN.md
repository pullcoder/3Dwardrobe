# 현재 기획 기준

프로젝트는 StyleFit AI로 전환했다. 현재 기준은 [PROJECT_PLAN.md](../PROJECT_PLAN.md)와 사용자 통합 개발 프롬프트 v2.0이다.
이전 CLOSET-VERSE 계획은 [archive/PLAN.md](archive/PLAN.md)에 보존하며 현재 범위에 적용하지 않는다.

현재 사용자 승인 범위는 3단계까지다. 기기 내 체형 분석·파라미터 3D 마네킹과 의류 분류·누끼·OCR·비공개 옷장을 구현했다.
의류 3D 생성(4단계)과 가상 피팅(5단계)은 다음 지시 전까지 착수하지 않는다.
실행·검증·미구현 항목은 [README.md](../README.md), [TASKS.md](TASKS.md), [3단계 검증 보고서](VERIFICATION_PHASE3.md)를 확인한다.
