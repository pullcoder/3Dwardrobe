# 현재 기획 기준

프로젝트는 StyleFit AI로 전환했다. 현재 기준은 [PROJECT_PLAN.md](../PROJECT_PLAN.md)와 사용자 통합 개발 프롬프트 v2.0이다.
이전 CLOSET-VERSE 계획은 [archive/PLAN.md](archive/PLAN.md)에 보존하며 현재 범위에 적용하지 않는다.

현재 사용자 승인 범위는 5단계 시각적 3D 피팅·코디 저장까지다. 기존 1~4단계는 유지하며 B 실제 생성은 여전히 비활성화다. 6단계 추천에 착수하지 않는다.
개인 마네킹·GLB의 동일 씬 장착과 부위별 변형, 제한적 관통 보정, 세 슬롯, 비공개 코디 복원을 제공한다. 물리 시뮬레이션·실제 착용감은 미지원이다. [5단계 설계](PHASE5_DESIGN.md), [검증](VERIFICATION_PHASE5.md).
정책 변경으로 3단계에 A 기본·권한 상태·증빙 참조 접수·원본 임시 보관을 반영한다. 4단계는 A 생성 우선, B는 증빙 검증 시스템 완성 후 구현하고 5단계는 공통 피팅 인터페이스를 사용한다. [정책 상세](RECONSTRUCTION_POLICY.md).
실행·검증·미구현 항목은 [README.md](../README.md), [TASKS.md](TASKS.md), [3단계 검증 보고서](VERIFICATION_PHASE3.md)를 확인한다.
