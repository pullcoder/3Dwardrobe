# PLAN — 기획 요약 · 기능 명세

> 출처: CLOSET-VERSE 사업계획서. 기획이 바뀌면 이 문서를 먼저 고치고, 이유는 `DECISIONS.md`에 남긴다.

## 1. 한 줄 정의

**CLOSET-VERSE** — AI 체형 분석 기반 3D 가상 옷장 및 크로스 피팅 커머스 플랫폼.
사진 한 장으로 내 체형과 내 옷장을 디지털화하고, 새 옷이 내 옷장과 얼마나 어울리는지 AI가 알려준다.

## 2. 해결하려는 문제

| 대상 | 문제 |
|------|------|
| 소비자 (B2C) | 모델 착용 사진으로는 **내 체형에서의 핏**을 알 수 없고, **내 옷과의 조합**도 확인할 수 없다 → 구매 보류·실패 구매 |
| 입점 브랜드 (B2B) | 온라인 패션 반품률 25~30%, 역물류 비용 부담. 3D 피팅 콘텐츠 제작비가 높다 |

## 3. 타깃

- **1차 타깃**: 온라인 쇼핑 빈도가 높고 트렌드에 민감한 20~30대 패션 고관여 소비자
- 시장 규모: TAM 약 30조 원 / SAM 약 1.5조 원 / SOM 약 800억 원

## 4. 차별점

| 기존 패션 플랫폼 | CLOSET-VERSE |
|-----------------|--------------|
| 모델 착용 사진 / 2D 룩북 | 사진 분석 + 치수 보정으로 만든 **개인 3D 아바타** |
| 쇼핑몰 판매 상품만 적용 | **소장 의류 + 판매 신상품** 복합 매칭 |
| 텍스트 후기·사이즈표 | 크로스 피팅 + **옷장 매칭 점수** + 체형 기반 사이즈 추천 |
| 구매·클릭 데이터 | 개인 옷장 인벤토리 + 동의 기반 체형 데이터 |

## 5. 사용자 흐름

1. **체형 등록**: 전신 사진 촬영 → MediaPipe 분석 → 치수 확인·보정 → 3D 아바타 생성
2. **옷장 등록**: 옷 사진 업로드 → 누끼·자동 태깅 → 디지털 옷장 저장
3. **크로스 피팅**: 쇼핑몰 상품 선택 → 옷장 속 하의·겉옷과 함께 착용 → 360° 확인
4. **AI 판단**: 옷장 매칭 점수 확인 → 빈자리 추천·사이즈 추천
5. **구매·저장**: 제휴몰로 이동해 구매 → 완성 코디를 옷장에 저장

## 6. 기능 명세

우선순위: **P0** = MVP(M+3) 필수, **P1** = 고도화(M+6), **P2** = 확장(M+12)

| ID | 기능 | 설명 | 우선순위 |
|----|------|------|---------|
| F1-1 | 전신 사진 업로드 | 정면 전신 사진 1장 업로드, 촬영 가이드 표시 | P0 |
| F1-2 | 배경 제거 | 사람 영역만 분리 (RMBG/SAM) | P0 |

| F1-5 | 수동 보정 | 몸무게, 가슴·허리·엉덩이 둘레 입력으로 추정값 보정 | P0 |
| F1-6 | 수치만 입력 | 사진 없이 치수만으로 체형 생성 | P0 |
| F1-7 | 원본 삭제 | 분석 완료 후 원본 사진 자동 삭제(기본값), 체형 데이터 삭제 기능 | P0 |
| F1-8 | 2.5D 아바타 | MVP용 경량 아바타(비율 기반 실루엣) | P0 |
| F1-9 | SMPL 3D 아바타 | 보정 치수 → SMPL 파라미터 → 인체 메시 | P1 |

**완료 기준 예시**: 키 175cm 입력 + 전신 사진 → 어깨너비·다리 길이 등 추정값이 표시되고, 사용자가 수정 후 저장할 수 있다.

## 7. 수익 모델 (참고)

- **CPS 수수료** (B2C): 제휴몰 구매 시 결제액의 6~12%
- **프리미엄 멤버십** (B2C): 옷장 무제한, 고정밀 3D 렌더링, 스타일 리포트
- **가상 피팅 위젯** (B2B): 위젯·API 월 구독
- **트렌드 데이터 리포트** (B2B)

## 8. 지켜야 할 제약

- **개인정보**: 얼굴·신체 사진은 분석 후 원본 삭제가 기본. 체형·사진 데이터 삭제 기능 제공.
- **라이선스**: SMPL 등 모델의 상업적 이용 가능 여부 확인, 대체 모델 검토.
- **정확도**: 사진 기반 3D 결과는 추정값임을 UI에 표시하고 수동 보정을 지원.
- **데이터 수집**: 크롤링 금지. 직접 업로드 사진과 제휴몰 제공 상품 정보만 사용.
- **비용**: GPU 비용·속도를 고려해 MVP는 경량 모델 + 2.5D 피팅으로 시작.
