# 의류 A/B 복원 정책

4단계에서 A의 실제 메시/GLB·영속 큐·뷰어와 관리자 증빙 검토를 추가했다. [현재 구현](PHASE4_DESIGN.md)을 함께 따른다. 권리 면제·법률 판단을 자동 제공하지 않는다.

## 모드

- A 기본: 종류·색상·길이·일반 실루엣을 분석해 독립 메시·재질을 생성한다. 원본 사진을 텍스처로 직접 복사하지 않고 보호되는 로고·일러스트·고유 그래픽의 무단 재현을 방지한다. 사진에 없는 치수와 보이지 않는 영역은 추정으로 표시한다. A도 적법한 입력·처리 권한이 필요하며 저작권·디자인권 침해가 자동 면제되지 않는다.
- B: 이용 권한을 검증한 의류에 한해 앞·뒤 사진으로 원본 색상·패턴·그래픽·로고·봉제선·주머니를 가능한 범위에서 재현하고 원본/결과 비교를 제공할 예정이다. 검증 시스템과 복원 엔진 구현 전까지 활성화하지 않는다.
- 두 모드 모두 사용자 계정에 비공개 저장한다. 공개 공유·판매·학습 재사용은 제외한다. 쇼핑몰 크롤링·타인 사진 무단 수집을 하지 않는다. 원본 삭제만으로 권리 문제가 해결되지 않는다.

세 권한을 독립적으로 확인한다: 입력 사진 처리, 보호되는 그래픽·디자인 복원, 생성 결과 저장·이용. 직접 촬영한 사실이나 체크박스는 세 권한의 증빙을 대체하지 않는다.

## 현재 등록 흐름

1. 사진 출처와 적법한 입력·처리 권한 안내 확인 후 사진 선택. 기존 분석 전송 동의를 별도로 받는다.
2. 로컬 분류·누끼·OCR 및 수동 수정. 사진 처리 권한은 사용자 확인 confirmed, 고정밀 복원/결과 이용 권한은 미확인으로 등록한다. 옷장에서 A 실제 3D 생성을 제공한다.
3. 의류 정보 저장 동의와 원본·누끼 보관 동의를 분리한다. 기본 temporary는 모든 이미지·누끼를 요청 후 폐기하고 정보·분석만 DB에 남긴다. 저장 성공 후 화면도 파일 참조를 해제한다. consented_storage 선택 시만 삭제할 때까지 원본·누끼를 비공개 보관한다. 물리적 메모리 완전 소거를 보장하는 의미는 아니다.
4. 본인 의류의 B 검토 신청에 참조와 실제 증빙 문서를 비공개 제출할 수 있다. URL을 자동 수집하지 않으며 참조 접수는 pending일 뿐 승인되지 않는다. 담당자가 세 범위를 실제 문서와 대조해 검토한다.
5. 기존 신고 접수·본인 상태 조회·관리자 검토 및 소유자 의류/계정 삭제를 유지한다. 외부 권리자 공개 신고 창구와 관리자 삭제·조치 이력은 출시 전 구현해야 한다.

증빙 원문 제출·관리자 승인/거절·검토 이력을 구현했다. 사용자가 verified를 직접 설정할 수 없다. 사진 미확인은 보류, 사진 confirmed/verified이면 A, 세 범위 verified이면 B를 자동 선택한다. B 실제 엔진은 준비되지 않아 선택되더라도 생성 요청은 503으로 차단한다. 신고/철회/거절은 생성·모델 이용을 중지한다. 생성 결과 경로와 검토 시각은 실제 처리 후 기록한다.

## B 승인 운영 원칙

로컬 관리자 키와 실제 문서·범위별 판단·근거·버전·시각 기록을 구현했다. 아래 기간/지역/자동 만료·담당자별 운영 인증은 후속 과제다.

1. 본인 의류 신청에 권리자 이용허락 문서·라이선스 원문을 인증된 비공개 증빙 저장소로 제출한다. 세 권한별 문서 참조·허용 범위·기간·지역·신청자/권리자 관계를 구분한다. 참조 접수만으로 검증하지 않는다.
2. 담당자가 문서 진위·허락 권한·대상 사진/의류/그래픽 대응·제3자 권리·결과 저장/이용 조건을 검토한다. 부족하면 보완 요청 또는 거절한다. 사용자 체크박스는 담당자 검증을 대체하지 않는다.
3. 세 권한별 판단·증빙 버전·담당자·근거·검토 시각·만료/철회 조건을 기록한다. 세 범위 모두 유효한 경우에만 서버가 approved 및 rights_reviewed_at을 기록한다. 거절은 rejected, 재신청은 새 버전의 pending으로 이전 승인 무효화.
4. 소유권·현재 권한 버전·철회/신고 상태를 등록 및 실행/조회 시 검사한다. 세 권한 검증 후 B를 자동 선택하되 기술 가용성까지 충족되어야 생성한다. 미확인·검토 중·거절 상태에서 B를 실행하지 않는다. 자동 만료/기간/지역 조건은 후속 운영 구현이 필요하다.
5. 신고·철회 시 B 작업/결과 이용을 차단하고 조사·삭제를 처리한다. 증빙과 검토 기록의 최소 접근 권한·보관 기간·삭제 근거를 확정한다. 문서 원문·사진·개인정보를 로그에 남기지 않는다.

## 4·5단계 연동

4단계 A는 일반 치수/태그에서 직접 제작한 메시와 단색 PBR 재질을 만든다. 사진 픽셀·로고·고유 그래픽의 텍스처 입력 경로가 없고 추정치 출처를 표시한다. SAM 누끼는 A 재질로 쓰지 않는다. 중간 데이터는 메모리에서 처리하고 서버 임시 파일을 만들지 않는다. 원본 비보관 의류는 사진이 필요한 후속 재분석 시 재업로드한다. B 실제 엔진은 기술/권리 검증 후 별도 개발한다.

5단계는 A/B 공통 GarmentModel 계약을 사용한다: 의류 ID·모드·인증된 비공개 모델 참조·단위/좌표계·피팅 기준점·치수 및 추정 출처. 같은 렌더링/피팅 인터페이스를 쓰고 모드별 생성 엔진에 의존하지 않는다. generated_model_path는 내부 비공개 참조이며 공개 URL/사용자 임의 경로가 아니다. 기존 model_3d_asset_id와 같은 인증 에셋에 연결한다.
