## 4단계 바지 품질 보완 (2026-11-03)

사진 외곽 49개 높이 프로필을 실제 바지 메시 기하구조에 반영한다. A는 자체 일반 체크, B는 세 권한 verified·저장 원본·지원 바지에 한해 앞면 투영 근사를 제공한다. 이전 문서의 B 전체 미지원 상태에서 이 제한된 범위만 확장했으며 고정밀 복원은 여전히 미구현이다. 와이드핏 보존·허리밴드/일반 주름·GLB 재로딩·기존 마네킹 장착을 검증한다. 다른 단계는 진행하지 않는다. [구현·전후 비교·실제 검증·한계](VERIFICATION_PANTS_QUALITY.md).
