# 4단계 바지 표면 품질 추가 보완

2026-11-03. 이전 외곽 반영만으로는 원단 표면이 여전히 둥글고 매끈하며 일반 체크가 크게 보였다. 이 요청은 기존 바지 품질 보완에만 한정한다. 새 AI 모델/가중치/외부 자산/외부 API를 도입하지 않았다.

## 실제 변경

- 초타원 단면: 타원형 원통보다 앞뒤가 평평하고 양옆에서 둥글어지는 천 패널로 변경했다. 기존 49행 사진 외곽과 치수 우선순위는 보존한다.
- 밑위: 두 바지통의 분리가 상부 골반까지 깊게 패이지 않도록 전환 구간을 아래로 내리고 smoothstep으로 연결한다.
- 드레이프: 잔물결 형태의 작은 사인 주름 대신 허리 아래부터 길게 내려오는 여러 폭의 일반 세로 주름을 실제 z 좌표에 반영한다. 임의 생성 주름이며 원본 주름 복원은 아니다.
- 열린 단: 허리/밑단의 가장자리를 안쪽으로 약8mm 접어 넣은 얇은 메시를 추가하고 밴드/박음선 요철을 표현한다. 전체 천의 물성/두께 시뮬레이션은 아니다.
- 음영: 앞뒤/좌우/의미 부위의 공유 좌표 법선을 평균해 보이는 연결선을 줄인다. 모델 버전은 stylefit-pants-2.1, 피팅 계약은 stylefit.pants.v2로 유지한다.
- 재질: 자체 일반 체크를1024×1536 미세 격자와 실 교차로 새로 만들었다. 원본 이미지의 체크 주기/픽셀/로고를 읽거나 복사하지 않는다. B는 기존 세 권한 verified 범위 내 앞면 투영을 유지하고 atlas를1536×1280으로 확장했다. 이전2.0 A 재질 검증도 유지한다.
- 뷰어: 화각/화면비에 맞춰 모델을 크게 배치하고 과도한 주변광을 줄여 표면 음영과 주름이 보이도록 했다. 메시 자체의 변경과 별개다.

| 항목 | 이전2.0 | 새2.1 |
|---|---:|---:|
| 정점 | 5,700 | 20,188 |
| 삼각형 | 10,560 | 38,784 |
| 실제 사용자 모델 GLB | 255,764 bytes | 1,120,328 bytes |
| 사진 외곽 높이 프로필 | 49 | 49, 유지 |

정점 개수는 복원 정확도의 지표가 아니다. 세로 주름·납작한 단면·접힌 가장자리와 연결 음영을 표현할 수 있도록 표면 표본을 늘렸다.

## 파일과 한계

변경: backend/app/services/{pants_mesh,pants_materials,garment_mesh}.py, backend/tests/test_pants_quality.py, frontend/src/features/garments/GarmentModelViewer.tsx, frontend/e2e/pants-quality.spec.ts, docs/{API,ARCHITECTURE,DECISIONS,VERIFICATION_PANTS_REFINEMENT}.md, AI_LICENSE_AUDIT.md, TECHNICAL_RISKS.md 및 기존 보고서의 후속 링크.

A의 자체 일반 패턴은 원본과 동일한 원단이 아니다. 뒷면·깊이·주름·접힌 단은 절차적 추정이며 실제 사진에 있는 주머니/고무줄/봉제를 정밀 복원했다고 주장하지 않는다. B도 한 장의 앞면 투영 근사다. 모든 삼각형 교차·원단 거동·착용감은 검증하지 못한다. 이전의 개인별 접근/증빙/권한 철회/삭제/비공개 저장 정책을 유지하며 원본을 외부로 전송하거나 학습에 사용하지 않는다. 다른 단계는 진행하지 않는다.

A의 미세 원단 UV는 표면 단면의 호 길이에 따라 배치해 옆면에서 체크가 늘어나는 현상을 줄인다. B의 앞면 투영 좌표는 별도로 유지한다.


생성 시간이 5초 poll 제한을 넘어 최종 모바일 재검증1건이 processing 상태로 시간 초과했다. 완료를 모사하거나 테스트를 skip하지 않고, 실제 생성/반복 검증에서 자체 원단 PNG만 색상별 최대8개 캐시하여 비용을 줄이고 poll 제한을20초로 맞췄다. 원본 사진/B 텍스처는 캐시하지 않는다. 최종 바지 pytest10개는15.19초에 통과했다.

최종 정면·측면·후면 개선 전후와 장착 비교 — 로컬 전용 `backend/storage/pants-quality/refinement/comparison.html`.

최종 A 원단 좌표·캐시 보완 후 PC/모바일 브라우저2개 모두 통과(40.2초). 새 GLB 재다운로드·앞/옆/뒤 렌더·마네킹 장착·모바일 넘침을 다시 확인하고 최종 스크린샷/비교 HTML을 갱신했다. 초기 시간 초과 기록은 위에 남긴다.
