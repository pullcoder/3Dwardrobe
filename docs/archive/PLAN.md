# PLAN — 기획 요약 · 기능 명세

> 출처: **CLOSET-VERSE 사업계획서 최종 (2026-11-02)**. 기획이 바뀌면 이 문서를 먼저 고치고, 이유는 `DECISIONS.md`에 남긴다.

## 1. 한 줄 정의

**CLOSET-VERSE** — AI 체형 분석 기반 3D 가상 옷장 및 크로스 피팅 커머스 플랫폼.
사진 한 장으로 내 체형과 내 옷장을 디지털화하고, 새 옷이 내 옷장과 얼마나 어울리는지 AI가 알려준다.

## 2. 단계별 인체 모델링 (가장 중요한 구조)

| 역할 | 기술 | 시점 |
|------|------|------|
| **분석** | MediaPipe Pose — 전신 사진에서 특징점(Keypoints)과 상대 비율 추출 | MVP부터 |
| **MVP 피팅** | MediaPipe 결과 + 사용자 입력 수치 → **2.5D 피팅 템플릿** → **2.5D 스키닝 기반 레이어드 뷰어** | M+3 |
| **고도화 피팅** | MediaPipe 수치 + 3D 인체 파라미터 → 개인화 **3D 메시 아바타**, 360° 회전 | M+6 이후 |

**라이선스 전략**: SMPL/SMPL-X는 MPI의 **비상업용 라이선스**다. 상용화 시점에는
① 정식 유료 라이선스 계약, 또는 ② 상업적 이용이 허용된 오픈소스 메시(MakeHuman 기반 인체 메시 등)를 사용한다.
→ 코드에 SMPL을 직접 넣지 않고, 인체 메시 모델을 교체 가능한 구조로 만든다. (`DECISIONS.md` D-010)

## 3. 해결하려는 문제

| 대상 | 문제 | 해결 |
|------|------|------|
| 소비자 (B2C) | 모델 컷만으로는 내 체형에서의 핏과 기존 소장 의류와의 조화를 알 수 없다 | 크로스 피팅 + 옷장 매칭 AI |
| 입점 브랜드 (B2B) | 반품·교환 역물류 비용, 고비용 3D 피팅 콘텐츠 제작 | **자동 에셋 변환 SaaS 위젯**: 2D 이미지 + 사이즈표 업로드 → AI가 2.5D/3D 에셋과 치수 매핑 자동 생성 |

## 4. 타깃 · 시장

- **1차 타깃**: 20~30대 패션 고관여 모바일 쇼핑 이용자
- **TAM 약 30조 원**: 통계청 온라인 쇼핑 동향, 연간 의류·패션 거래액
- **SAM 약 1.5조 원**: 모바일 패션 플랫폼·테크 솔루션 적용이 활발한 온라인 패션 거래액의 약 5%
- **SOM 약 800억 원**: 20~30대 고관여 이용자 약 600만 명 × 연 의류 구매액 약 130만 원 × 1%

## 5. 차별점

| 항목 | 기존 플랫폼 (무신사·지그재그·에이블리 등) | CLOSET-VERSE |
|------|------------------------|--------------|
| 피팅 시각화 | 전문 모델 사진, 2D 룩북 | MediaPipe 기반 2.5D 뷰어(MVP) → 3D 아바타(고도화) |
| 적용 의류 | 플랫폼 판매 신상품만 | **소장 의류 + 판매 신상품** 복합 매칭 |
| 구매 판단 근거 | 텍스트 후기, 사이즈표 | 크로스 피팅, 옷장 매칭 점수, 체형 기반 사이즈 추천 |
| 데이터 자산 | 구매·클릭 로그 | 옷장 인벤토리 + 동의 기반 체형 수치 |

## 6. 사용자 흐름 (MVP 기준 UI)

1. **체형 등록**: 전신 사진 촬영 또는 수치 입력 → MediaPipe 분석·신체 비율 산출 → 2.5D 피팅 템플릿 연동
2. **옷장 등록**: 옷 사진 업로드 → 누끼 + VLM/OCR 자동 태깅 → 디지털 옷장 저장
3. **크로스 피팅**: (MVP) 2.5D 레이어드 뷰어에서 쇼핑몰 상품과 내 옷을 겹쳐 코디 확인 / (고도화) 3D 아바타 360° 회전
4. **AI 판단**: 옷장 매칭 점수(70점 이상 벌 수) 확인, 빈자리·사이즈 추천
5. **구매·저장**: 제휴몰로 이동해 구매, 완성 코디 저장

### F4. 옷장 활용도 AI 추천

| ID | 기능 | 설명 | 우선순위 |
|----|------|------|---------|
| F4-1 | 옷장 매칭 점수 | 새 옷과 옷장 속 옷 각각의 조합 점수(0~100). **70점 이상 = 어울리는 코디**. UI: "옷장 속 7벌과 70점 이상으로 어울립니다" | P0 |
| F4-2 | 빈자리 추천 | 옷장에서 부족한 아이템 도출 → 제휴몰 상품 연계 | P1 |
| F4-3 | 체형 기반 사이즈 추천 | 체형 치수 vs 상품 사이즈표 → 최적 핏 판정 | P1 |
| F4-4 | 코디 추천 | 신체 비율 + 취향(캐주얼·스트릿 등) 반영, 추천 이유 제시 | P1 |
| F4-5 | 추천 바로 입혀보기 | 추천 결과 클릭 → 피팅 뷰어 | P0 |

**매칭 점수 산출 로직** (단순 코사인 유사도의 보완)
- 입력: VLM이 추출한 색상 톤, 소재, 패턴, 스타일 태그 (옷장 아이템과 신상품 양쪽)
- 연산: **컬러 하모니 룰**(보색·유사색·톤온톤·무채색 조합 등) + **스타일 매칭 가중치** + 태그 임베딩 **코사인 유사도**를 복합 연산
- 출력: 0~100점 정수, 임계값 70 (설정값으로 조정 가능)

## 11. 지켜야 할 제약

- **개인정보**: 얼굴·신체 원본 사진은 분석 즉시 안전 삭제가 기본값. 사용자 데이터 삭제 권한 보장.
- **라이선스**: SMPL 계열은 비상업용. 상업 허용 오픈소스 메시 또는 정식 상용 라이선스만 사용.
- **정확도**: 사진 기반 수치는 추정값 → UI에 표시하고 수동 보정 제공.
- **크롤링 금지**: 유저 업로드 사진과 제휴몰 공식 오픈 API/데이터만 사용.
- **비용**: 경량 모델 + 2.5D 우선, 비동기 큐로 GPU 비용 최소화.
